# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-06

### Added

- automated download and provenance capture for UNEP IMEO Eye on Methane MARS GeoJSON;
- schema normalization and deterministic record-level QA/QC;
- GeoPackage output and lightweight GeoJSON sample;
- PostgreSQL/PostGIS schema and idempotent loader;
- machine-readable QA summaries in CSV and JSON;
- automated tests;
- Docker packaging;
- publication-grade figures using the Agropixel visual palette;
- 13-page illustrated technical report;
- split licensing for code versus derived UNEP-data assets;
- CITATION.cff and publication metadata for GitHub/Zenodo;
- publication checklist and release notes.

### Scope boundary

Version 1.0.0 does not implement methane retrieval, radiative transfer, plume detection, machine learning, or independent methane-emission quantification.
